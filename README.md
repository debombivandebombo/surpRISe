# surpRISe
Simulator Under Reconfigurable Propagation in RIS Environments

---

## 📥 Installation

To install the **surpRISe** package, follow the method below:

### From a local file (`.whl`)

1.  Download the package file (`.whl`) provided by the developer.
2.  Open a terminal (Command Prompt on Windows or Terminal on macOS/Linux).
3.  Navigate to the directory where you saved the `.whl` file using the `cd` command. For example:
    ```bash
    cd C:\Users\YourUser\Downloads
    ```
4.  Execute the following command to install the module:
    ```bash
    pip install surpRISe-0.1.0-py3-none-any.whl
    ```
5.  Once the installation is complete, the module will be ready to use in your projects.

---

## 🔄 Update package

To update the **surpRISe** package, follow the method below:

### From the terminal with `setup.py` file

1.  Open a terminal (Command Prompt on Windows or Terminal on macOS/Linux).
2.  Navigate to the directory of the project root (surpRISe/) with `cd` command. For example:
    ```bash
    cd C:\Users\YourUser\Documents\GitHub\surpRISe\
    ```
3.  Execute the following command to update the module:
    ```bash
    python setup.py sdist bdist_wheel
    ```

### If there is any problem, try to fix it with the next steps:

1.  Open the terminal to update/install the next packages either in general python or the virtual environment you are using.
2.  Execute the following commands:
    ```bash
    pip install wheel
    pip install --upgrade pip setuptools
    ```
